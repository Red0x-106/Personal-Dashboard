# Personal Dashboard

A simple personal dashboard I made for myself.

I wanted one place where I could see my tasks, projects, coding time, study time, notes, and my current goal.

## What it has

- Live clock and date
- Tasks with saved checkboxes
- Project progress
- Focus timer
- Notes that save in the browser
- Coding time
- Study timer
- Useful links
- Main goal section
- Responsive layout for smaller screens

## What I used

- HTML
- CSS
- JavaScript
- localStorage

## What I learned

While making this, I got more practice with JavaScript and connecting it with HTML and CSS.

I also learned how to use localStorage to save things like tasks and notes even after refreshing the page.

## Project

This was made as a personal project while I was learning frontend development.

I kept the project simple because I wanted to understand how each part works instead of making it overly complicated.

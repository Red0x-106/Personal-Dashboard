# Personal Dashboard

A simple personal dashboard I made for myself.

I wanted one place where I could see my tasks, projects, coding time, study time, notes, and my current goal without having to use different websites or apps for each thing.

https://red0x-106.github.io/Personal-Dashboard/

## What it has

- Live clock and date
- Tasks with saved checkboxes
- Project progress
- Focus timer
- Notes that save in the browser
- Coding time
- Study timer
- Useful links
- Main goal section
- Responsive layout for smaller screens

The different sections are meant to work together as one dashboard. I can use the task section for things I need to finish, keep notes in the notes section, track study or coding time, and see my project progress and current goal from the same page.

## How it works

The dashboard runs directly in the browser using HTML, CSS, and JavaScript.

The live clock updates while the page is open. Tasks can be checked off, timers can be used for focused work or studying, and notes can be written directly on the dashboard.

Some of the information is saved using `localStorage`, which means things like tasks and notes can stay saved when the page is refreshed.

## How to use it

There is nothing to install.

1. Open the Personal Dashboard website.
2. Use the different sections of the dashboard for tasks, notes, timers, projects, and other information.
3. Add or update tasks when needed.
4. Use the focus or study timer when working.
5. Add notes and refresh the page to see that saved information stays there.
6. Use the useful links and goal section when needed.

The dashboard works in a normal modern web browser.

## Help

If something doesn't appear to work correctly, refreshing the page can help.
